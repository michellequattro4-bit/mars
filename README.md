# MARS

Статическая страница входа с центральной карточкой Liquid Glass и русским интерфейсом. Используются только HTML, CSS и JavaScript, без сборки, npm, библиотек и внешних запросов.

## Как открыть

Откройте `index.html` двойным щелчком в современном браузере. Стили и скрипт подключены относительными путями, поэтому страница работает через `file://` и при размещении в любой папке статического сайта.

## Структура

```text
mars/
├── README.md
├── index.html
├── styles.css
└── script.js
```

## Возможности

- Адаптивная карточка входа шириной до 440 px.
- Поля почты и пароля с подписями и автозаполнением.
- Показ и скрытие пароля.
- Проверка обязательных полей и формата почты с русскими сообщениями.
- Клавиатурный фокус и поддержка уменьшенного движения.
- Системный стек шрифтов: Inter, системные шрифты Apple, Segoe UI, sans-serif. Шрифты не скачиваются.

Это демонстрация интерфейса без серверной авторизации. После успешной проверки появляется сообщение «Форма заполнена корректно». Данные не отправляются и не сохраняются. Кнопка «Забыли пароль?» показывает подсказку об обращении к администратору.
